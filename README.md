## 🎓 Sobre este Projeto

Este é um projeto desenvolvido inteiramente por mim com o objetivo de consolidar e praticar conceitos fundamentais da programação. Ele serviu como laboratório para aplicar na prática o que estudei sobre Programação Orientada a Objetos (POO) em Python, manipulação de dados e estruturação de sistemas modulares.

O sistema simula uma concessionária online onde o cliente realiza seu cadastro e tem seus dados armazenados de forma persistente em arquivos CSV. A aplicação conta com validação de login e senha, exibição de estoque interativa e um filtro inteligente que sugere veículos com base no orçamento informado pelo usuário. Ao final do fluxo, o cliente pode selecionar o automóvel desejado e agendar o melhor dia e horário para que a equipe comercial entre em contato.
## 🔮 Evoluções Futuras

Este software está em sua versão inicial utilizando arquivos CSV para persistência. Pretendo continuar evoluindo este repositório com as seguintes implementações:

- **Migração para Banco de Dados:** Substituir os arquivos CSV por um banco de dados relacional **SQL** (como SQLite ou PostgreSQL) para garantir maior integridade e escalabilidade dos dados.
- **Relatórios:** Geração de arquivos PDF com o resumo dos agendamentos realizados.
- **Mensagem Automatica:** O sistema manda mensagens automaticas para o cliente via e-mail ou celular.
